# TheQuad

Private repository. Internal use only.

## Setup

```bash
npm i
```

Create `.env` with:

```
VITE_SUPABASE_URL=<project_url>
VITE_SUPABASE_ANON_KEY=<anon_key>
```

Values from Supabase: Project Settings → API.

## Run

```bash
npm run dev
```

## Stack

- React + Vite + TypeScript
- Supabase (auth, db, storage, realtime)
- Tailwind CSS
